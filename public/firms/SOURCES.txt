To replace a logo, drop the new file in this folder under the same name. To add a firm, add the file here
and a line in src/data/firms.ts. A firm with no `logo` is shown as its name in type. SVG files are shown
as plain images, so nothing inside them can run; keep them free of scripts all the same.
